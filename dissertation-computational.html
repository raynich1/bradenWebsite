Calculations and computation

Calculations for the design were broadly separated into mechanical and thermal. Mechanical calculations were simple enough to use standard relationships for:

  1. Hertz contact stresses given a cylindrical pin contact with a hole.
  2. A stress concentration at the edges of the pin-loaded hole.
  3. Pin shear stress (and bending induced by imperfect geometry).

This did not stretch far beyond the things already present in an undergraduate engineering curriculum. Out of curiosity, though,

The complexity of the system meant a thorough computational solution for its thermal characteristics was near impossible, and the mechanical components were easy enough to calculate conventionally that simulations were not needed. Simulation work therefore was not part of my dissertation, but at some points throughout the project I set up some simulations out of curiosity, some of which aided minimally in the design. They were all done with ANSYS. For the electromagnetic/thermal simulations, I found the Python API to be nice and intuitive (much better than working with the UI!) while for the mechanical simulations I simply worked with the UI, but made a note that I should get used to that Python library as well since it will ultimately make running simulations much more efficient (after the learning curve is passed).
